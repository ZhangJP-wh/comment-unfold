# 评论全开

<img src="logo.png" alt="评论全开" width="160">

在 YouTube、哔哩哔哩和小红书的网页里，点一下就能把当前评论区里折叠的回复展开，并尽量把后面的评论继续加载出来。所有操作都发生在你自己的浏览器页面里，扩展不会把评论内容上传到任何地方。

英文目录名是 `comment-unfold`。安装时选择的就是这个文件夹。

## 支持的页面

- YouTube 观看页：`youtube.com/watch`，以及直播页 `/live/`
- 哔哩哔哩普通视频页：`bilibili.com/video/`
- 小红书网页版笔记：`xiaohongshu.com` 的笔记详情。人在海外时，小红书有时会跳到 `rednote.com`，这个域名也一起适配了

不支持手机版站点（例如 `m.bilibili.com`）、YouTube Shorts，以及哔哩哔哩的动态、专栏页。

## 安装

用的是 Chrome 的「加载已解压的扩展程序」，不需要上架商店。

1. 用 Chrome 打开 `chrome://extensions`
2. 打开右上角的「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选中本项目里的 `comment-unfold` 文件夹（这个文件夹里面能直接看到 `manifest.json`）
5. 工具栏出现「评论全开」。如果没看到图标，点工具栏的拼图按钮，把「评论全开」固定出来

改完代码后，回到 `chrome://extensions`，在这张卡片上点刷新即可。

## 怎么用

1. 打开上面任意一个支持的视频或笔记
2. 点工具栏里的「评论全开」图标，或点页面右下角的绿色「展开评论」按钮。这一下会展开评论，并把评论区变暗、正文留亮
3. 再点一次工具栏图标，或点页面上的「关闭高亮」：只去掉变暗，已经展开的回复还在，方向键翻页也还在
4. 第三次点工具栏图标，或点页面上的「恢复收起」：停掉还没点完的展开，收起**这次扩展自己展开**的回复，并关掉翻页和高亮。打开扩展之前你已经展开的回复不会去动
5. 第四次点工具栏图标，又回到第 2 步
6. 展开自然结束后会停在当前这一态，不会自己关掉。页面上的状态按钮在还没展开完时再点，不会中途停止；展开到上限之后，点绿色按钮是继续展开，不是退出

绿色按钮展开时会写成「展开中…」，结束后会写结果，例如「已展开当前评论」。

扩展会自己去点页面上的「展开」「查看更多」「N 条回复」「Show more replies」这类按钮，也会把评论区往下滚，让网站自己加载下一批。它不会替网站发明一套新的评论列表。

## 评论区变暗

点工具栏的「评论全开」，或点页面上的「展开评论」开始展开时，扩展会给**当前评论区**盖一层灰色。只有评论正文保持原来的亮度，正文周围是一圈紧贴文字的亮块。作者名、头像、等级或徽章、发表时间、点赞数、回复按钮仍然是暗的。正文里的表情、链接和 @ 算在正文里，保持清晰。

这层灰色只盖评论区本身，不盖整页：

- YouTube、哔哩哔哩右侧的推荐视频不动
- 播放器、顶栏，以及评论区外面的页面不动
- 小红书左侧的笔记图片和正文不动，只处理右侧评论区
- 楼中楼回复的正文同样保持清晰，作者和时间仍然变暗

新展开的回复、后面加载出来的评论、滚动、窗口大小变化、换页之后，亮块会跟着正文走。灰色层不接收点击，选字、点赞、滚动和方向键翻页都照常。

变暗只在第一次点开之后出现。点「关闭高亮」或再点一次工具栏图标就去掉灰色，展开和翻页还留着。点「恢复收起」或第三次点工具栏图标，会把这次扩展展开的回复尽量收回去。换到另一个视频或笔记时，这次会直接结束，不会自动再开，也不会去点收起。

能收回的，是扩展这次点过的「展开回复 / Show more replies / 展开 N 条回复」后面出现的「收起」「隐藏回复」「Hide replies」「Show less」。打开扩展之前就已经展开的，不会去点。

这些收不回来，扩展也不会删页面、不会刷新：

- 往下滚、或网站自己追加的评论（YouTube 顶层无限下拉、小红书滚进屏幕才出现的评论）
- 你自己用方向键翻过的页
- 网站没有提供收起按钮的那一段

已经展开的评论会留在页面上。播放进度、滚动位置和正在输入的内容都不会被刷新清掉。

## 评论区本身是翻页时

有的评论区不能拼成一条无限长的列表，翻页会换成另一页。哔哩哔哩展开后，评论或楼中楼底部常出现「共 N 页、页码、下一页、收起」这样的分页条。这时：

1. 鼠标移到评论区，会出现一行半透明提示：「点击此区域后，可用左右方向键翻页」
2. 提示不挡点击，鼠标可以照常点赞、回复
3. 在评论区里点一下（不是在输入框里），这行提示会消失
4. 之后按左方向键上一页，右方向键下一页
5. 焦点在输入框、文本框里时，方向键仍然用来移动光标，不会翻页
6. 按 Esc，或点评论区外面，就会取消翻页，避免影响视频快进

楼中楼自己还有翻页按钮时，鼠标放在那一楼里，方向键翻的是这一楼，不是整页评论。

## 隐私

- 不收集评论正文，不上传，不需要登录你的账号
- 没有远程服务器。扩展只在当前标签页里点击和滚动网站原来的界面
- 单次大约最多点击 70 次，或持续约 45 秒，避免不停请求

## 已知限制

**YouTube**

- 评论要等页面自己先把评论区渲染出来。扩展会把评论区滚进视野再开始
- 顶层评论是无限下拉，不是传统翻页，所以这里没有方向键翻页
- 一次做不完时按钮会写「已到本次上限，可再点一次继续」
- 很短的评论没有「显示更多」，不会被误点。播放器上的「展开」也不会被点到

**哔哩哔哩**

- 主评论是一页一页换掉的，没法在不改网站的前提下合成一整条无限列表。扩展会展开当前页的「共 N 条回复，点击查看」，翻页交给上面的方向键
- 新版评论在多层 Shadow DOM 里，选择器按 2026 年网页结构来写。网站再改版的话，按钮可能会暂时找不到评论区
- 未登录时，部分评论或楼中楼可能不出现
- 本机如果被哔哩哔哩风控页拦住（常见提示是访问被拒绝），要先在浏览器里手动打开视频并完成验证，扩展才能看到评论区

**小红书**

- 很多笔记不登录就看不到完整评论。页面上会先出现登录提示
- 笔记有时是弹层，地址不一定变化。只要评论区已经出现，右下角按钮或工具栏图标就能用
- 评论如果用了虚拟列表，滚出屏幕的那一段可能被网站回收，扩展只能展开当时还在页面上的内容
- 海外网络打开 `xiaohongshu.com` 可能会被带到 `rednote.com`。笔记页的评论类名（例如评论容器、`展开 N 条回复`）和国内网页是同一套

## 目录

```
comment-unfold/
  manifest.json          扩展清单（Manifest V3）
  icons/                 工具栏图标
  src/service-worker.js  工具栏图标被点击时通知页面
  src/page-bridge.js     在页面里触发网站原来的按钮
  src/content.js         右下角按钮、展开过程、换视频后重新绑定
  src/focus.js           只把评论区变暗，正文留亮，可取消
  src/adapters.js        三个网站各自的评论区找法
  src/pager.js           翻页提示和方向键
  src/shared.js          文本判断、次数上限、穿透 Shadow DOM
```

本仓库不包含 `tests/` 目录。安装和使用只需要上面的 `comment-unfold/` 文件夹。
